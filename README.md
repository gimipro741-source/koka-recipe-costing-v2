# حلواني قوقه — KOKA Recipe & Costing

نسخة تطوير مستقلة عن Higgsfield، مبنية بـ React + Vite، مهيأة للفتح في Codex أو VS Code.

## التشغيل

```bash
npm install
npm run dev
```

افتح العنوان المحلي الذي يظهر في الطرفية (عادة http://localhost:5173).

## ما تم تنفيذه
- صفحة مقدمة متحركة: شيف افتراضي SVG أصلي متحرك، بطاقات Glassmorphism، حركات hover وscroll.
- أربعة أقسام بمرئيات وحركات مختلفة: المخبوزات (قمح/دقيق/نشابة)، التورت (فواكه)، المشروبات (قهوة/حمضيات)، الشرقي (سميد/فستق).
- لوحة تحكم، دفتر وصفات بصفحتين وتقليب، خامات قابلة للتعديل، حساب تكاليف، تقارير، طباعة وتصدير CSV.
- شعار KOKA الرسمي كما أرسله العميل محفوظ في public/koka-official-logo.png. لا تستخدم تكبيره كخلفية عملاقة لأنه صورة منخفضة الدقة.
- الأسعار بالجنيه المصري EGP. وصفات تجريبية فقط، ليست بيانات المصنع الحقيقية.
- بيانات المعاينة تُحفظ في localStorage في المتصفح الحالي.
- تقليل الحركة وإتاحة prefers-reduced-motion.

## قبل الإنتاج
1. PostgreSQL + API + صلاحيات وتسجيل دخول حقيقي.
2. ربط الشيف بكل قسم، دورة اعتماد آمنة على الخادم، سجلات تدقيق ونسخ وصفات.
3. استيراد وتنظيف ملفات Excel والتحقق من صلتها بمصنع قوقه.
4. وحدات تحويل ومقادير دقيقة وتكلفة التغليف والعمالة والهالك.
5. تدقيق حسابات التكلفة ومراجعة قابلية الوصول واختبارات متصفح.
